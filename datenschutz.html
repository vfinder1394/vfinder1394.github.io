YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

What data is accessed, used and stored

  • Permission requested: youtube.upload only. The tool does not read any YouTube data (no channel data, comments, subscribers or analytics).
  • Sent to YouTube: the owner's own video file with title, description, tags and scheduled publish time.
  • Stored: only the OAuth refresh token of the channel owner, on the owner's own computer. Nothing else is stored.
  • Shared: no data is shared with third parties, sold or used for advertising. No cookies, no tracking.

Revoking access

Access can be revoked at any time via the Google security settings page: security.google.com/settings/security/permissions.

Deletion

Revoking access invalidates the stored token; the local token file is then deleted. As no other data is stored, nothing else needs to be deleted. Deletion requests can be sent to the contact below and are completed within 7 days.

Datenschutzerklärung

YouTube API Services

Dieses Werkzeug nutzt die YouTube API Services. Wer es nutzt, stimmt den Nutzungsbedingungen von YouTube zu. Siehe auch die Datenschutzerklärung von Google.

Welche Daten verarbeitet werden

Angefragt wird nur die Berechtigung youtube.upload. Es werden keine YouTube-Daten gelesen. An YouTube gehen nur die eigenen Videos mit Titel, Beschreibung, Tags und Veröffentlichungszeit. Gespeichert wird ausschließlich der OAuth-Token des Kanalbetreibers auf dessen eigenem Rechner. Keine Weitergabe an Dritte, keine Werbung, keine Cookies.

Widerruf und Löschung

Der Zugriff lässt sich jederzeit unter security.google.com/settings/security/permissions widerrufen; danach wird die lokale Token-Datei gelöscht. Weitere Daten werden nicht gespeichert. Löschanfragen an die Kontaktadresse werden innerhalb von 7 Tagen erledigt.
